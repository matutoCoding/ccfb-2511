# 公路标志标线夜间视认性仿真系统

浏览器内运行的夜间视认性仿真:TypeScript + WebGPU,无渲染引擎依赖,
车灯配光、逆反射、眩光全部按光度学模型自行计算。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 打包到 dist/
```

需要支持 WebGPU 的浏览器(Chrome/Edge 113+、Safari 18+、Firefox 141+)。
不支持时系统给出明确提示;道路方案、标志库、报告页不依赖 GPU,仍可使用。

## 页面

| 页面 | 功能 |
|---|---|
| 道路方案 | 平曲线(直线/缓和曲线/圆曲线)+ 纵坡(变坡点+抛物线竖曲线)生成路线;横断面、标线类型、标志布设;多方案管理,localStorage 保存,JSON 导出/导入 |
| 标志库 | 反光膜逆反射系数 RA 表(观测角×入射角),可编辑/新增 |
| 夜间仿真 | 驾驶员视角匀速行驶,近/远光切换,雨天湿滑,对向车眩光开关,HUD 实时显示前方标志亮度 |
| 报告 | 标志亮度-距离曲线(固定步长采样),导出 CSV / PNG,对数坐标切换 |
| 设置 | 车速、眼高、灯高、湿滑、采样步长;数据导入导出/恢复出厂 |

## 光度学模型(核心公式)

**标志(逆反射)亮度**,单位 cd/m²:

```
E⊥ = Σ_i I_i(H,V) / d_i²        两只前灯在标志处的垂直照度 (lx)
L  = RA(α, β) · c · E⊥          RA: 逆反射系数 cd/(lx·m²),c: 版面颜色系数
```

- `I(H,V)` 为前照灯发光强度表(cd):近光为非对称配光(左侧水平截止线 -0.57°、
  右侧 15° 上抬、峰值约 2 万 cd),远光峰值约 10 万 cd。按水平/垂直角查表 +
  双线性插值,**不是简单聚光灯**;超出配光范围视为无光。
- `α` 观测角:标志→灯中点 与 标志→眼 的夹角;`β` 入射角:标志→灯 与 版面法线的夹角。
  RA 表中间角度双线性插值,超出表范围取边界值(不外推)。
- 彩色版面按颜色系数折减(黄 0.62 / 红 0.15 / 绿 0.12 / 蓝 0.05 …)。

**标线亮度**:`L = RL · E面`,RL 为逆反射亮度系数(mcd/(m²·lx),换算 ×1e-3),
E面 为路面照度;雨天按湿滑程度在干燥 RL 与潮湿 RL 间内插,沥青反射率同步降低并加湿路镜面反射。

**对向车眩光**(CIE 146 失能眩光):`Lv = 10 · E眼 / θ²`(θ 单位度),
作为光幕亮度叠加到场景全部亮度上,可开关。

## 确定性与一致性

- 全部光度计算为 CPU 双精度纯函数,无任何随机数、无依赖帧率的积分;
  同一位置重复计算结果逐位一致(已在浏览器内验证)。
- 报告页曲线与仿真页 HUD 数字调用同一套 `signPhotometry()` 函数,同源同值。
- 道路几何采样步长固定(平面 0.25m 中点积分、网格 2m),网格与角度结果唯一。

## 性能

道路网格一次构建、相机移动;每帧仅绘制前方 500m 窗口(约 500 个三角形),
标志亮度每帧只算可见的若干块(每块几次查表插值)。80 km/h 下计算量与车速无关,不卡。

## 主要假设(可根据实测标定)

- 配光表为代表性数据(`src/optics/headlamp.ts`),如有实测灯具 IES 数据可替换为实测表;
- 反光膜 RA 表为各等级代表性最小值(`src/defaults.ts`),可在标志库页改为厂家实测值;
- 双灯车辆的 α、β 按两灯中点计算,照度按两灯分别计算后叠加;
- 标志版面按均匀亮度处理(未做版面上逐点变化)。
